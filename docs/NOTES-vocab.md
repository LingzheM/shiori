# 実施ノート — 語彙（生词系统）v1

> 2026-07-18 · 核心命题：复习不是一个动作，是阅读的副产品

## 关键决策与理由

**D1 · 生词是全局的，不分书。**
不认识的词在哪本书里都不认识。存储键 `dokusho:vocab`，条目：`{word, sentence, bookId, chapterId, para, t, known}`——出处仅作溯源，匹配作用于所有章节。

**D2 · 数据分两层：亲手标的（珍贵）与脚本回填的（可再生）。**
用户词表在 localStorage；读音/释义/活用形在仓库的 `public/vocab.json`（fetch，404 视为"尚未回填"，静默）。两层在运行时合并。**这个分层意味着：清了浏览器数据，损失的只是词表本身——所以「全バックアップ」按钮进了 v1**，请定期点一下把 JSON 存到备忘录/文件里。

**D3 · 匹配是最长优先的单次正则，活用形靠回填数据解决。**
阅读器不做形态分析（不背分词器的体积和复杂度）。动词变形（食べた≠食べる）由 vocab.json 的 `forms` 数组穷举——**这个活儿交给生成 vocab.json 的脚本/skill**，它比任何客户端分词器都便宜且准。畳語、副词、名词天然不变形，无需 forms。

**D4 · 下划线不改变字形度量。**
`text-decoration` 不影响排版，分页的页数、每页内容零扰动——生词标记的开关不会让你"丢页"。

**D5 · 保存的确认反馈 = 词自己亮起来。**
无 toast。addWord → 匹配器失效重建 → 该词当场出现点线。状态即反馈。

**D6 · 重标一个已「毕业」的词 = 自动恢复它。**
你又选中了它，说明其实没记住。known 置回 false，点线回来。

## vocab.json 规格（给你的回填脚本 / skill）

**输入**（阅读器「語彙」标签 →「未補完を書き出し」，剪贴板 JSON）：

```json
[
  { "word": "痛感する", "sentence": "……を痛感した。" }
]
```

**输出**（写入 `public/vocab.json`，与已有内容**合并**，git push）：

```json
{
  "痛感する": {
    "reading": "つうかんする",
    "meaning": "中文释义（面向 N1 学习者，可含用法辨析）",
    "forms": ["痛感し", "痛感した", "痛感して", "痛感します"]
  }
}
```

规则：键 = 用户标注的原样；`reading` 全假名；`forms` 列出正文中可能出现的表层形（动词/形容词必填，不变形词给空数组）；`meaning` 语言随你——建议中文为主。
**建议给你的 en-ja-nonfiction skill 加一条命令**（如「補完」）：输入剪贴板 JSON，输出合并后的 vocab.json——和「用語」命令是近亲，提示词改造量很小。

## 使用循环（完整走一遍）

読む → 长按选词 →「＋語彙に追加」→ 点线立现 → （攒一批）→ 語彙タブ「未補完を書き出し」→ 跑脚本/skill → vocab.json 入库 push → 此后每次重逢：点词看读音释义 → 真记住了点「もう覚えた」→ 列表变短

## 真机验证清单

- [ ] 长按选中一个词 → 胶囊出现在选区上方，不被刘海/工具栏遮挡
- [ ] 点「＋語彙に追加」→ 选区消失，该词立刻带点线
- [ ] 该词在**其他章节**出现处也带点线
- [ ] 点带点线的词 → 词卡升起；分页模式下**不翻页**，滚动模式下**不切换工具栏**
- [ ] 未回填的词 → 词卡显示「未補完」提示
- [ ] push 含该词的 vocab.json 后刷新 → 词卡显示读音与释义（含 forms 的变形处也命中）
- [ ] 「もう覚えた」→ 全书该词点线消失；語彙タブ「覚えた」区可「↺」恢复
- [ ] 書き出し按钮 → 剪贴板得到合法 JSON
- [ ] 深色主题下点线可见但不刺眼

## 已知边界（记录在案）

- 匹配按表层字符串，同形异义词（如「甘い」的两义）会共用一张词卡——释义里写全两义即可
- 选区最长 30 字符、不跨段——防误存整句
- 词卡打开期间遮罩全屏，需先关卡再操作其他 UI
